# Football Executive Management Web App
Standalone browser prototype for the current Football Executive Management project.

Roles: Club Chairman / Football Association President. Manager Mode is excluded; Manager is NPC/Staff.

Includes Dashboard, Match Center, Club, Squad, Staff, Finance, League, Association and World Football sections; role switching; responsive layout; prototype match result interaction.

Important: this is a standalone UI prototype and is not connected to the Unity runtime. Unity remains authoritative.

Run: open `index.html` in a modern browser, or run `python -m http.server 8080` in this folder.
